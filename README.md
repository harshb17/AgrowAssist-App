# 🌱 AgrowAssist - Smart Agricultural Assistance System

AgrowAssist is an AI-powered mobile application built with Flutter to help farmers and agricultural professionals make informed decisions. The app leverages TensorFlow Lite models to provide crop recommendations, plant disease detection, fruit identification, health classification, and agricultural analytics through an intuitive user interface.

> **Status:** 🚧 Actively maintained

---

## ✨ Features

- 🌱 Smart Crop Recommendation based on soil and environmental parameters.
- 🦠 Plant Disease Detection using AI-powered image classification.
- 🍎 Fruit & Crop Identification from images.
- 🩺 Fruit Health Classification (Healthy / Rotten).
- 📊 Crop Analytics and insights.
- 📚 Farming knowledge and best practices.
- 🌐 Offline support for AI-powered predictions.
- 🗣️ Multi-language support (English, Hindi, Marathi, Gujarati).

---

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **Machine Learning:** TensorFlow Lite
- **Image Processing:** Image Picker
- **UI:** Material Design
- **Platform:** Android

## 🤖 AI Models

The application integrates multiple TensorFlow Lite models for:

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/harshb17/AgrowAssist-App.git
cd AgrowAssist-App
```

### Install dependencies

```bash
flutter pub get
```

### Run the application

```bash
flutter run
```

> Ensure all required assets (images and TensorFlow Lite models) are present in the project before running the application.
